# Independently authored Carousel body

`body.glb` is a unit-metre +Y-up/+Z-front model with static `CarouselRoot`,
`DeckRoot`, roof and mast; `RotorRoot` owns the deck and16 sculpted horses.
`Seat_00` through `Seat_15` are direct rotor anchors. Four external portal
markers are empties; their pixels/geometry are not fabricated original objects.

Geometry is independently generated by
`prototypes/detailed-assets/sources/carousel.py`. CC0 material files and licence
evidence are in `material-provenance.json`; no original game sprites are shipped.
The packed editable Blender master is retained on WD, not rebuilt on Patrick's
Mac. `source-manifest.json` records the measured export. Detailed evidence and
the finite candidate/reference boundaries are in
`docs/verification/carousel/README.md`.
