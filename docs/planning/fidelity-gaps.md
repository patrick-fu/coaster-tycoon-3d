# Fidelity gaps and discriminating acceptance cases

This register is a test-design contract. None of its future cases is reported
as executed merely because research found a plausible rule. Exact-original
cases need original inputs/observations; candidate correctness cases run remotely
first. The delivered kernel, Classic library and asset/surface checkpoint cases
cover only their recorded profiles and do not qualify the full content programme.

## Required evidence per case

Record source/version, evidence class, content/recipe/profile hash, seed,
tick-indexed commands, starting saved state, expected transition/quote/output,
actual trace and relevant screenshot, remote environment/command/exit, verdict
and residual uncertainty. Render verification adds camera/light/asset hashes.
Separate structural correctness, original agreement, capacity and human visual
acceptance. Never infer original physics from a matching silhouette.

geometry mapping; native physics/ratings/dispatch/timing arithmetic; service
