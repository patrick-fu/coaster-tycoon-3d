# Independently implement the game under MIT

Patrick selected MIT and an independent project on 2026-10-03. Implement the
game's simulation, presentation and metadata independently, using RCT2 as a
gameplay reference; the project is unaffiliated with RCT2 and OpenRCT2.

The OpenRCT2 core-reuse experiment is discontinued. Its GPL-licensed
implementation is outside the selected production route. Use dependencies
compatible with the MIT project, preserve their notices, and record separate
third-party asset permissions. The first playable game must run with its own
resources and must not require players to provide original game files.

Existing source research is historical behavioral evidence, not permission to
copy implementation or proof of a formal clean-room process. Independent
simulation behavior and original-scale performance require their own validation.
