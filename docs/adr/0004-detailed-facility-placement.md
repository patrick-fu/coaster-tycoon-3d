# Preserve old facilities while adding detailed placement profiles

The compact candidate facility reserves16 native height units. A detailed
independently authored building can approach3.85m at the current4m/tile mapping.
Changing the old identity's reservation would invalidate legal old parks with
an overpass atbase+16; retaining16 for a taller model would permit visual overlap.
The current generic fitModel also rescales each axis, conflicting with ADR0003.

Introduce two new detailed object variants with a separate finite numeric
facility placement profile in complete saved Rules. Old variants remain16;
new profile is fixed32 and available only with qualified4m mapping/commerce.
Use explicit save13/content6/protocol6 receiving/migration, validated v12 commerce
continuation and unit-scale authored presentation. Restrict the new capability
to dry ground until variable supports are independently qualified.

A fixed registry-only height can work but would require another receiving/mapping
availability convention outside saved numeric Rules. Reusing old identity cannot
support old16 and new32 in one park. Squashing models or changing all old clearances
is rejected. The additional profile is bounded to the two representative variants;
no general building/height editor or speculative commercial system is added.

This decision preserves earlier park authority and enables measured asset
integration. It requires old-v12 witnesses, explicit placement/migration seams,
actual model/runtime checks and remaining human/original/GPU qualification.
[Finite contract](../planning/detailed-consumable-stalls.md) owns details.
