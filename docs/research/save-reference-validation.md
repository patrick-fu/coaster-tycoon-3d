# Save Compatibility and Reproducible Validation Options

Research date: 2026-10-03. OpenRCT2 evidence is pinned to `11513222890717e81431c83a28aafb7555f2ccd2`. This report identifies options for the browser 3D project; original-save compatibility and exact numerical parity remain open decisions.

**Dependencies and reproducibility**

Parsing bytes precedes loading required objects and importing playable state; missing objects can raise `ObjectLoadException`. S6 also adds modern terrain, station, music, peep-animation and climate dependencies. [Load pipeline](https://github.com/OpenRCT2/OpenRCT2/blob/11513222890717e81431c83a28aafb7555f2ccd2/src/openrct2/Context.cpp#L773-L787), [missing objects](https://github.com/OpenRCT2/OpenRCT2/blob/11513222890717e81431c83a28aafb7555f2ccd2/src/openrct2/object/ObjectManager.cpp#L543-L578), [dependency expansion](https://github.com/OpenRCT2/OpenRCT2/blob/11513222890717e81431c83a28aafb7555f2ccd2/src/openrct2/rct2/S6Importer.cpp#L1948-L1986). Optional packed objects are not a complete asset bundle: normal packing selects loaded custom objects. Interactive OpenRCT2 requires original object files containing graphics, sounds and models. [Packing selection](https://github.com/OpenRCT2/OpenRCT2/blob/11513222890717e81431c83a28aafb7555f2ccd2/src/openrct2/object/ObjectManager.cpp#L281-L294), [installation requirements](https://github.com/OpenRCT2/docs/blob/86cf40e575605df295c57e97049c67a5108e982c/installing/getting-rct2.rst#L4).

Record a manifest with fixture hash/origin, engine commit, object identifiers/content hashes, import mode, patches, cheats/plugins, full starting state, tick, date and both RNG words. S6 restores `GameTicks1` and two scenario RNG seeds; `.park` persists tick/date and both RNG words. Scenario import can apply patches, and normal park loading recalculates valuations: capture the boundary before comparing values. [S6 state](https://github.com/OpenRCT2/OpenRCT2/blob/11513222890717e81431c83a28aafb7555f2ccd2/src/openrct2/rct2/S6Importer.cpp#L364-L367), [park state](https://github.com/OpenRCT2/OpenRCT2/blob/11513222890717e81431c83a28aafb7555f2ccd2/src/openrct2/park/ParkFile.cpp#L638-L675), [patches](https://github.com/OpenRCT2/OpenRCT2/blob/11513222890717e81431c83a28aafb7555f2ccd2/src/openrct2/rct2/S6Importer.cpp#L605-L621), [valuations](https://github.com/OpenRCT2/OpenRCT2/blob/11513222890717e81431c83a28aafb7555f2ccd2/src/openrct2/Context.cpp#L805-L817).

`S6ImportExportTests` imports `BigMapTest.sv6`, exports `.park`, reloads it, and checks entity snapshot differences; another case advances 1,000 ticks before export. It is not SV6-to-SV6 or whole-state equality. [Test implementation](https://github.com/OpenRCT2/OpenRCT2/blob/11513222890717e81431c83a28aafb7555f2ccd2/test/tests/S6ImportExportTests.cpp#L111-L275). Replay stores starting park/global parameters/cheats, tick-ordered commands with within-tick ordering, and entity checksums; the replay harness checks for playback mismatch. Ride-rating tests compare recomputed values with text fixtures. These are OpenRCT2 regression facilities, not vanilla oracles. [Replay state/order](https://github.com/OpenRCT2/OpenRCT2/blob/11513222890717e81431c83a28aafb7555f2ccd2/src/openrct2/ReplayManager.cpp#L51-L104), [replay harness](https://github.com/OpenRCT2/OpenRCT2/blob/11513222890717e81431c83a28aafb7555f2ccd2/test/tests/ReplayTests.cpp#L70-L102), [rating assertions](https://github.com/OpenRCT2/OpenRCT2/blob/11513222890717e81431c83a28aafb7555f2ccd2/test/tests/RideRatings.cpp#L60-L109).

**Preparation agents can own**

- Prepare three independent acceptance records: parser success (decoded fields/errors), playable compatibility (resolved objects, placement and simulation), and behavioral parity (matched inputs and observed outputs against a named baseline). A successful earlier stage does not imply the next.
- Author synthetic codec/invalid-input fixtures and an independently created minimal track/park corpus with explicit provenance. Existing Sawyer tests demonstrate fixed byte arrays and malformed-input checks without a running original game. [Codec tests](https://github.com/OpenRCT2/OpenRCT2/blob/11513222890717e81431c83a28aafb7555f2ccd2/test/tests/SawyerCodingTest.cpp#L37-L181).
- Prepare tick-indexed command logs and checkpoint fields for finance, ratings, path/queue connectivity, guests, rides and objectives; extend beyond entity-only checks. Inventory definitions separately from media before attempting headless simulation. Headless/no-graphics bypasses install prompting/base graphics, but required object loading remains. [Headless gates](https://github.com/OpenRCT2/OpenRCT2/blob/11513222890717e81431c83a28aafb7555f2ccd2/src/openrct2/Context.cpp#L400-L408), [graphics gate](https://github.com/OpenRCT2/OpenRCT2/blob/11513222890717e81431c83a28aafb7555f2ccd2/src/openrct2/Context.cpp#L476-L481).
- Audit candidate fixture authorship, embedded objects and permitted handling before reuse. The tracked corpus includes SV6, park and SEA files; no per-fixture provenance manifest was found in the inspected tree. The repository GPL statement is not fixture-by-fixture clearance. [Fixture directory](https://github.com/OpenRCT2/OpenRCT2/tree/11513222890717e81431c83a28aafb7555f2ccd2/test/tests/testdata), [license statement](https://github.com/OpenRCT2/OpenRCT2/blob/11513222890717e81431c83a28aafb7555f2ccd2/readme.md#L146-L147).

Original-RCT2 parity needs a runnable, identified original build and authorized data access. Agents can prepare bounded command scripts and observation sheets; original tick stepping/RNG access is unverified. OpenRCT2 explicitly changes guest/staff AI and limits, so agreement with it cannot establish original numerical or behavioral parity. [Documented differences](https://github.com/OpenRCT2/OpenRCT2/blob/11513222890717e81431c83a28aafb7555f2ccd2/readme.md#L66-L68).

**Browser persistence options**

IndexedDB supports asynchronous structured data/blobs; OPFS offers private byte-oriented files. Both remain subject to origin storage management; persistence requests can be denied and site-data deletion still matters. [IndexedDB](https://developer.mozilla.org/en-US/docs/Web/API/IndexedDB_API), [OPFS](https://developer.mozilla.org/en-US/docs/Web/API/File_System_API/Origin_private_file_system), [quotas/eviction](https://developer.mozilla.org/en-US/docs/Web/API/Storage_API/Storage_quotas_and_eviction_criteria). Portable local export can use a Blob URL/download link and import through file selection. `showSaveFilePicker()` is an optional enhancement requiring HTTPS/user activation with limited browser availability. [Blob URLs](https://developer.mozilla.org/en-US/docs/Web/API/URL/createObjectURL_static), [download](https://developer.mozilla.org/en-US/docs/Web/API/HTMLAnchorElement/download), [local file selection](https://developer.mozilla.org/en-US/docs/Web/API/File_API/Using_files_from_web_applications), [picker constraints](https://developer.mozilla.org/en-US/docs/Web/API/Window/showSaveFilePicker). A project-owned versioned schema remains an option; browser storage does not select an RCT compatibility target or authorize media redistribution/server upload.
